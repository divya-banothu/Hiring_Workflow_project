# Generated output

Run the generator to populate this folder. Start with `--scale starter` to check your environment. Use `--scale full` to generate the assignment's target volumes.

The generated data files are excluded from Git by `.gitignore` to avoid committing large derived artifacts. The source code, schema, data dictionary, tests, and instructions should be committed. If the client explicitly requests sample outputs in the repository, remove the relevant ignore entries and include only the small starter output.
